解释：

加密的步骤分解（正向）：

(x >> 5)取高 3 位，移到低 3 位位置，其余高位是 0（因为 x 是 8 位）。

(x << 3)取低 5 位，移到高 5 位位置，低 3 位补 0。

然后做 |合并，结果还是 8 位（& 0xFF是防止左移 8 位时溢出到更高位，这里实际上 8 位 x 左移 3 位时，在 8 位内会有高 3 位移出，但用 32 位存储再 &0xFF 就保留低 8 位）。

用二进制看（假设 x 的 8 位是 a7 a6 a5 a4 a3 a2 a1 a0）：

x >> 5= 00000 a7 a6 a5(低 3 位是 a7 a6 a5)

x << 3= a4 a3 a2 a1 a0 000`(高 5 位是 a4 a3 a2 a1 a0，低 3 位是 0)

合并 = (a4 a3 a2 a1 a0) (a7 a6 a5)（注意这里的括号是分开两部分）

这相当于把 x 的高低两部分交换了：

原来 x = [a7 a6 a5] [a4 a3 a2 a1 a0]

加密后 y = [a4 a3 a2 a1 a0] [a7 a6 a5]

这是循环左移 3 位！

验证：循环左移 3 位，就是取出高 5 位，低 3 位挪到高 3 位位置，再合并。

确实，你的式子与循环左移 3 位一致。
