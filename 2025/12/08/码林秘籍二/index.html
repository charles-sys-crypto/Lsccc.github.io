性质3：若二叉树有n0个叶子、n2个度为2的数据，则必存在关系式：n0 = n2 + 1。

证明：

  1. 设二叉树上结点总数：n = n0 + n1 + n2
  2. 设二叉树上分支总数为b，由树的性质：n = b + 1
  3. 然后根据结点和分支的关系，b = n1 + 2n2
  4. 所以n = n1 + 2n2 + 1
  5. 联立1和4，得到 n0 = n2 + 1

1.3二叉树的存储结构

1.3.1二叉树的顺序存储结构

  • 数组描述除了存储数据，还需要存储双亲/孩子关系。
  • 对完全二叉树，在数据编号和数组下标之间建立对应关系，即0号数据存储于下标为0的数组元素，1号数据存储于下标为1的数组元素，…，以此类推。
  • 根据性质5，根据数据所在数组元素的下标，可以计算出其双亲和左、右孩子所在的数组元素的下标。即通过数组元素下标的计算表示双亲/孩子关系。
