性质3：若二叉树有n0个叶子、n2个度为2的数据，则必存在关系式：n0 = n2 + 1。

证明：

  1. 设二叉树上结点总数：n = n0 + n1 + n2
  2. 设二叉树上分支总数为b，由树的性质：n = b + 1
  3. 然后根据结点和分支的关系，b = n1 + 2n2
  4. 所以n = n1 + 2n2 + 1
  5. 联立1和4，得到 n0 = n2 + 1

1 二叉树的遍历方法及其实现

遍历的定义： 顺着某一条搜索路径寻访二叉树中的结点，使得每个结点均被访问一次，而且仅被访问一次

作用： 遍历的目的是线性化，使二叉树中的结点能够按照某种次序列排列在一个线性队列上，便于处理

二叉树是层次结构，非空的二叉树由根、左子树和右子树三部分组成，因此，遍历二叉树有三种途径：

  • 自顶向下按层次的遍历。
  • 先左(子树)后右(子树)的遍历。
  • 先右(子树)后左(子树)的遍历。

1.1先序遍历

若二叉树为空树，则空操作，否则

  1. 访问根结点
  2. 先根遍历左子树
  3. 先根遍历右子树

4 树和森林与二叉树的对应关系及遍历

4.1树和森林与二叉树的对应关系

树与二叉树的对应关系： 给定一棵树，通过树的二叉链表表示法可以找到唯一的一棵二叉树与之对应。树的二叉链表的右子树一定是空的。

森林与二叉树的对应关系： 将森林中的第二棵树看成第一棵树的兄弟即可。

二叉树转换成森林

  1. 抹线：将二叉树中根结点与其右孩子连线，及沿右分支搜索到的所有右孩子间连线全部抹掉，使之变成孤立的二叉树
  2. 还原：将孤立的二叉树还原成树

由树、森林和二叉树的相互转换可知，树和森林的各种操作均可与二叉树的各种操作相对应。不过，和树对应的二叉树，其左、右子树的概念已改变为： 左子树是孩子，右子树是兄弟。

4.2树的遍历

先根(次序)遍历:若树不空，则先访问根结点，然后依次先根遍历各棵子树。

A>B>E>F>C>D>G>H>I>J>K

后根(次序)遍历:若树不空，则先依次后根遍历各棵子树，然后访问根结点。

E>F>B>C>I>J>K>H>G>D>A

按层次遍历:若树不空，则自上而下自左至右访问树中每个结点。

A>B>C>D>E>F>G>H>I>J>K

4.3森林的遍历

森林可以分解成三部分：

  1. 森林中第一棵树的根结点
  2. 森林中第一棵树的子树森林
  3. 森林中其他树构成的森林
4.3.1森林的先序遍历

若森林不空，则

  1. 访问森林中第一棵树的根结点
  2. 先序遍历森林中第一棵树的子树森林
  3. 先序遍历森林中的（除第一棵树之外）其余树构成的森林

即：依次从左至右对森林中的每一棵树进行先根遍历

4.3.2森林的中序遍历

如果森林不空，则

  1. 中序遍历森林中第一棵树的子树森林
  2. 访问森林中第一棵树的根结点
  3. 中序遍历森林中（除第一棵树之外）其余树构成的森林

即：依次从左至右对森林中的每一棵树进行后根遍历
