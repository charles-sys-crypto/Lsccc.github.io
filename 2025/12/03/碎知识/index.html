纸条二

带泛型的接口，带泛型的类，以及实现带泛型接口的泛型类

带泛型的接口：

有什么用呢？

定义一种与具体数据类型无关的、可被多种不同类型安全实现的通用契约（结构）。

带泛型的类：

有什么用呢？

允许我们编写一个与特定数据类型无关的通用类。在创建这个类的实例时，我们再指定它具体要处理哪种类型的数据，从而获得类型安全、消除强制转换，并最大化代码复用

带泛型的接口只能限制实现接口的类中，接口的那些抽象方法的类型。

而实现类还可以有除了接口以外的其他方法/字段，再用自己的泛型来限制。

场景 类声明 接口实现 是否合规 说明
1 class C<T> implements I<T> ✅ 类型参数传递
2 class C<T,U> implements I<T> ✅ 部分参数对应
3 class C implements I<String> ✅ 接口类型具体化
4 class C<T> implements I<String> ✅ 但怪 类的 T 在接口方法中没用上
5 class C implements I ⚠️ 原始类型 编译器警告，不推荐
6 class C<T> implements I<Number> ✅ 固定为父类型
